# CO2 Emissions in the German Energy Sector: An AI Investigation 🌍
**Big Data & Predictive Analytics for Climate Impact**

## 📌 Project Overview
This project, developed for the **Business Project in Big Data & AI** module at GISMA University, investigates greenhouse gas trends within Germany. It utilizes Machine Learning to analyze carbon footprints and provide data-driven insights for the German energy transition (Energiewende).

## 🚀 Key Features
- **Time-Series Analysis:** Analyzing historical CO2 data to identify seasonal and industrial patterns.
- **Predictive Modeling:** Forecasting future emission levels based on energy consumption metrics.
- **German Market Focus:** Specifically tailored to EU environmental regulations and German Federal Environment Agency (UBA) standards.

## 🛠️ Tech Stack
- **Languages:** Python
- **Data Science:** Pandas, NumPy, Scikit-learn
- **Visualization:** Matplotlib, Seaborn (for trend analysis)

## 📊 Business Significance
This tool assists stakeholders in visualizing the impact of energy policies, helping organizations align with Germany's goal of climate neutrality by 2045.
The collection of data is from https://data.europa.eu/data/datasets/6deb4df0-f20b-4572-a497-77deb1adc877?locale=en
